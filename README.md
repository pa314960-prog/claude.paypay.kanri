# PayPay 明細ビューア

PayPay からダウンロードした取引履歴 CSV を、ブラウザだけで集計・可視化するツールです。
`index.html` を開くだけで動きます。ビルドもサーバーも不要で、読み込んだ明細が
どこかへ送信されることはありません。

## 公開URL

**https://pa314960-prog.github.io/claude.paypay.kanri/**

GitHub Pages で公開しています（`main` ブランチのルート）。上の URL を開けばそのまま使えます。
インストールもアカウント登録も不要です。

## 使い方

1. PayPay の取引履歴を CSV でダウンロードする（アプリの取引履歴画面、または Web 版の利用明細）
2. `index.html` をブラウザで開く
3. CSV をドラッグ＆ドロップする（複数ファイルをまとめて読み込めます）

CSV を持っていない場合は、画面の「サンプルデータで試す」から動きを確認できます。
`sample/paypay-sample.csv` は同じ内容のファイルで、ドラッグ＆ドロップの確認に使えます。

## できること

- **サマリー** — 支出合計・入金合計・収支・件数・1回あたりの支出。支出合計には前月比を表示
- **月別の支出と入金** — 柱グラフ。柱をクリックするとその月に絞り込み
- **曜日別の支出** — 曜日ごとの合計・件数・平均
- **支出の内訳** — カテゴリ / 取引先 / 取引方法 で切り替え。行をクリックするとその条件で絞り込み
- **明細表** — 並べ替え、行を開くと取引番号や支払い区分などの元データを表示
- **絞り込み** — 期間（プリセット・カスタム）、支出/入金、カテゴリ、取引方法、キーワード
- **書き出し** — 絞り込んだ結果を CSV でダウンロード、またはクリップボードにコピー
- グラフはすべて「表」表示に切り替え可能。明るい画面／暗い画面の切り替えあり

## 読み込みについて

- **文字コード** — UTF-8（BOM 付きを含む）、Shift_JIS、EUC-JP を自動判定します
- **列の対応づけ** — 見出し名で判定するため、列の並び順が違っても読み込めます。
  `取引日` `出金金額(円)` `入金金額(円)` `取引内容` `取引先` `取引方法` `支払い区分` `取引番号` などに対応。
  `出金`/`入金` の代わりに符号付きの `金額` 列しかない形式にも対応します
- **見出しより前の行** — 前置きの行があっても、見出し行を探して読み始めます
- **重複** — 複数ファイルを読み込んだとき、同じ取引番号の明細は取り込みません
- 日付か金額を読み取れない行（小計行など）は飛ばし、その件数を画面に表示します

## カテゴリの判定

取引先と取引内容のキーワードから、コンビニ・スーパー・飲食・交通・公共料金などに自動で振り分けます。
判定できないものは「その他」になります。ルールは `index.html` の `CATEGORY_RULES` にまとまっているので、
自分の使う店を足すとそのまま反映されます。

## プライバシー

- 明細はブラウザのメモリ上でのみ扱い、サーバーへの送信も保存も行いません
- ページを閉じるか再読み込みすると、読み込んだ明細は消えます
- 外部への通信は Web フォントの取得のみです。オフラインでも（フォントが代替になるだけで）動作します

## 開発

単一ファイル構成です。依存パッケージはありません。

```
index.html                 ツール本体（HTML / CSS / JavaScript）
.nojekyll                  GitHub Pages で Jekyll の処理を通さないための空ファイル
sample/paypay-sample.csv   動作確認用のサンプル明細
scripts/build-artifact.js  Artifact 公開用の HTML を dist/ に生成する
```

PayPay は PayPay株式会社の登録商標です。このツールは同社とは関係のない個人的なユーティリティです。
